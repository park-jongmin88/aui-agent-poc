# 의존성 정의 (requirements 생성 기준)

폴더 생성 후 requirements 를 채울 때 **이 파일을 기준으로 읽어** 반영한다.
버전을 바꾸거나 의존성을 추가하려면 이 파일만 수정하면 된다. (코드 하드코딩 금지)

## 필수 의존성 (무조건 포함)
- mlflow=={version}
- kserve==0.15.0

`{version}` 은 트래킹 URL 에서 조회한 MLflow 버전으로 치환된다.
조회 실패 시 기본값 `3.10.0` 을 사용한다.
