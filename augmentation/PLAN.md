# Augmentation (데이터 증강) - 계획

<br>

## 목적

Dataset Builder 파이프라인에서 증강이 필요할 때, 기법별로 데이터를 증강한다.

<br>

## ⚠ 우선순위 판단

포털에 워크스페이스 UI 를 구축하고 백엔드는 검증된 오픈소스 증강 엔진을
기법별로 임베딩하여 연동하는 설계는 가능하나, **수요 대비 개발 난이도/복잡도가
높을 것으로 예상됨. 후순위 권장.**

<br>

## 증강 기법 (5가지)

```
1. Doc to Q&A          문서 → 질의응답 쌍 생성
2. 질의 다변화          같은 의도의 질문을 여러 표현으로
3. 적대적 환각 유발증강  할루시네이션 유도 케이스 생성
4. 약점보강증강         모델이 취약한 부분을 보강
5. 커스텀 템플릿         사용자 정의 템플릿 기반
```

<br>

## 왜 복잡한가 — 단일 오픈소스 통합 불가

기법별로 서로 다른 오픈소스 엔진을 각각 임베딩해야 한다. 하나로 퉁칠 수 없음.

**후보 오픈소스**
```
- Ragas
- DeepEval
- Distilabel
- TextAttack
```

<br>

## 하고 싶은 것 (착수 시)

- 기법별 오픈소스 매핑 확정 (예: Doc to Q&A → Ragas, 적대적 → TextAttack 등)
- 기법 하나만 먼저 붙여서 최소 검증 (전체 5개 한번에 X)
