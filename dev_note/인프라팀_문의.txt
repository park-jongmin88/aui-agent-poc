제목: [AI-Studio] MLflow AI Gateway 관련 문의 2건 (임베딩 엔드포인트 / 자동평가 인증)


안녕하세요.

AI-Studio GenAI Agent 관련하여 MLflow AI Gateway 설정 2건 문의드립니다.


────────────────────────────────────────────────────
1. RAG 임베딩용 Gateway 엔드포인트 등록 요청
────────────────────────────────────────────────────

[요청]
RAG 임베딩용 gateway 엔드포인트를 등록해 주실 수 있는지 문의드립니다.

[배경]
- 현재 gateway 생성 UI 에는 type 선택이 없어, 생성 시 무조건
  /v1/chat/completions (chat) 형식으로만 만들어집니다.
- 임베딩은 /v1/embeddings (input 형식) 이라 별도 등록이 필요합니다.
- 아래 설정으로 gateway YAML 에 등록이 필요할 것으로 보입니다.
    endpoint_type : llm/v1/embeddings
    모델          : bge-m3
    주소          : embedding.llm.(도메인).com/v1

[사유]
현재 RAG 임베딩은 gateway 를 거치지 않고 임베딩 서버를 직접 호출하고 있습니다.
위 엔드포인트가 등록되면 임베딩도 LLM 과 동일하게 gateway 를 통해
호출하도록 통일할 수 있습니다.


────────────────────────────────────────────────────
2. 자동 평가(judge) 실행 시 Gateway 인증 문의
────────────────────────────────────────────────────

[문의]
MLflow 서버가 자동 scorer(judge) 를 실행할 때, gateway 호출에
Basic 인증(아이디:비번)을 실을 수 있는지 문의드립니다. (서버 설정으로 가능한지)

[배경]
- judge 자동 평가는 MLflow 서버가 저장된 judge 를 불러와 gateway 를
  호출하는 구조입니다.
- gateway 는 Basic 인증을 요구하는데, 서버가 자동 실행 시 인증을 싣지 않아
  "권한 오류(You are not authenticated)" 가 발생합니다.
- 애플리케이션 코드로는 해결이 어렵습니다. judge 에 인증정보를 저장하는
  방법(make_judge 의 extra_headers)이 있으나, register(등록) 시
  직렬화에 포함되지 않아 저장되지 않는 것을 확인했습니다(MLflow 3.13).

[확인 부탁드리는 사항 — 아래 중 가능한 방법이 있는지]
  1) MLflow 서버가 자동 scorer 실행 시 gateway 로 인증을 보내도록
     서버 측에서 설정할 수 있는지
  2) gateway 가 서버 내부 호출에 대해서는 인증을 면제할 수 있는지
  3) 인증이 필요 없는 LLM 엔드포인트를 judge 전용으로 사용할 수 있는지

[사유]
위 중 하나가 가능하면 자동 평가(새 대화를 실시간 자동 채점)를 사용할 수 있습니다.
불가능하면 현재처럼 수동 평가(스크립트 실행)만 사용할 예정입니다.
(참고: LLM 답변 생성·수동 평가는 애플리케이션이 직접 인증 헤더를 실어
 정상 동작하며, 자동 평가만 서버가 호출하는 구조라 막혀 있습니다.)
