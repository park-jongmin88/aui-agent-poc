# 게이트웨이_사용정리.md

이 프로그램에서 MLflow AI Gateway 를 어디에, 어떻게 쓰는지 정리한다.

<br>

## 요약

LLM 은 항상 **MLflow AI Gateway** 를 통해 호출한다. 실제 LLM 주소·키는 gateway 가
가지고 있고, 이 프로그램은 gateway 만 부른다. gateway 는 호출 시 MLflow 계정
(아이디:비번) 기반 **Basic 인증**을 요구하므로, 호출하는 쪽이 인증 헤더를 실어야 한다.

<br>

## 게이트웨이를 쓰는 곳 (3군데)

<br>

### 1. LLM 답변 생성  ✅ 정상

- **파일**: `assets/llm.py`
- **언제**: 사용자가 대화할 때 (에이전트가 답변 생성)
- **방식**: `ChatOpenAI(base_url=".../gateway/mlflow/v1", default_headers=Basic인증)`
- **인증**: 우리 코드가 헤더에 Basic 인증을 직접 넣는다 → 통과

<br>

### 2. 게이트웨이 엔드포인트 조회/선택  ✅ 정상

- **파일**: `assets/gateway_utils.py`
- **언제**: `agent.py` 등록 시 LLM 선택, `judge_register.py` 평가 LLM 선택
- **방식**: REST 호출 (`/api/3.0/mlflow/gateway/endpoints/list`)
- **인증**: Basic 인증 헤더 → 통과

<br>

### 3. Judge 평가용 LLM  ⚠️ 자동만 문제

- **파일**: `judge_register.py`, `evaluate.py`
- **언제**: judge 가 답변을 채점할 때
- **방식**: `make_judge(model="gateway:/<엔드포인트명>")`
- **인증**:
  - **수동 평가**(`evaluate.py` 직접 실행) → litellm 몽키패치로 헤더 주입 → 통과 ✅
  - **자동 평가**(자동 트래킹, 서버가 실행) → 인증이 judge 에 저장되지 않아 실패 ❌

<br>

## 정리 표

| 용도 | 파일 | 인증 방식 | 상태 |
|------|------|-----------|------|
| LLM 답변 생성 | `assets/llm.py` | 헤더에 Basic | ✅ |
| 게이트웨이 조회 | `assets/gateway_utils.py` | 헤더에 Basic | ✅ |
| Judge 수동 평가 | `evaluate.py` | litellm 몽키패치 | ✅ |
| Judge 자동 평가 | (MLflow 서버가 실행) | 저장된 인증 없음 | ❌ |

<br>

## 왜 자동 평가만 안 되나

핵심은 **"누가 gateway 를 호출하느냐"** 이다.

- **우리 코드(프로세스)가 호출** → 우리가 인증 헤더를 넣을 수 있음 → 정상
  (LLM 답변 생성, 게이트웨이 조회, judge 수동 평가)
- **MLflow 서버가 호출** → 우리 코드가 개입 못 함 → 인증 못 넣음 → 실패
  (judge 자동 평가)

<br>

자동 평가는 MLflow 서버가 **저장된 judge** 를 불러와 gateway 를 호출한다.
그런데 `make_judge(extra_headers=...)` 로 인증을 넣어도, `register()` 로 저장할 때
extra_headers 가 직렬화에 포함되지 않아(3.13 확인) 서버가 인증 없이 gateway 를
호출하게 된다. → 권한 오류.

> 검증: 로컬에서 `make_judge` 직후엔 extra_headers 가 있으나, `register()` 후
> `list_scorers` 로 다시 불러오면 사라짐(`instructions_judge_pydantic_data` 에
> instructions/model/feedback_value_type 만 저장됨). 코드 문제가 아니라 MLflow 한계.

<br>

## 대응

<br>

**현재 (권장)**  — 자동 평가는 보류, 수동 평가(`evaluate.py`)만 사용.
수동 평가는 정상 동작하며, 원하는 시점에 원하는 trace 를 평가할 수 있다.

<br>

**자동 평가를 살리려면**  — 다음 중 하나가 필요(인프라/서버 영역).

1. MLflow 서버가 자동 scorer 실행 시 gateway 로 인증을 보내도록 서버 설정
2. gateway 가 서버 내부 호출에는 인증을 면제
3. 인증이 필요 없는 LLM 엔드포인트를 judge 모델로 사용
   (단, 사내 폐쇄망에서 접근 가능하고 인증이 불필요해야 함)

<br>

## 관련 파일

- `assets/llm.py` — LLM(gateway) 호출
- `assets/gateway_utils.py` — 게이트웨이 조회 공통 모듈
- `judge_register.py` / `evaluate.py` — judge 등록/평가
- `check_judge.py` — 등록된 judge 의 인증헤더 저장 여부 확인(진단)
- `dev_note/JUDGE_GATEWAY_AUTH.md` — judge-게이트웨이 인증 상세
